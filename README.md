# Space Bounty API

Spring Boot 3.2.3 REST API using Java 17, Spring Web, Spring Data JPA, and PostgreSQL.

## Requirements

- Java 17+
- Maven 3.9+
- PostgreSQL 14+
- Docker Desktop with Docker Compose

## Run with Docker Compose

Docker Compose starts the Spring Boot API and PostgreSQL together. No local Java, Maven, or PostgreSQL installation is needed:

```bash
docker compose up --build
```

Wait for the `db` health check and the Spring Boot startup message, then use the API at `http://localhost:8080`. The first startup builds the application image and seeds 5 criminals and 10 hunt logs. PostgreSQL data is kept in the `postgres_data` Docker volume between restarts.

Useful commands:

```bash
# Run in the background
docker compose up --build -d

# View application logs
docker compose logs -f app

# Stop the containers, keeping database data
docker compose down

# Stop containers and delete the seeded database volume
docker compose down -v
```

The included Postman collection uses `http://localhost:8080` and works with the Docker setup without changes.

## Run locally

Create a database named `space_bounty`, then start the application:

```bash
export DATABASE_URL=jdbc:postgresql://localhost:5432/space_bounty
export DATABASE_USERNAME=postgres
export DATABASE_PASSWORD=postgres
mvn spring-boot:run
```

Hibernate creates/updates the tables and the application seeds 5 criminals and 10 hunt logs on an empty database. Environment variables are optional when using the defaults shown above.

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/api/criminals/` | List criminals; supports `min_reward`, `max_reward`, `armed`, `has_crew`, `escape_master`, and `sort=reward` or `sort=-reward` |
| GET | `/api/criminals/{id}/` | Criminal details |
| GET | `/api/hunts/` | List hunt logs; supports `criminal_id` |
| GET | `/api/hunts/{id}/` | Hunt log details |
| POST | `/api/hunts/` | Create a hunt log |
| PATCH | `/api/hunts/{id}/` | Update `success` and/or `notes` |
| DELETE | `/api/hunts/{id}/` | Delete a hunt log |

Example create request:

```json
{
  "criminal_id": 3,
  "success": false,
  "notes": "Target escaped through an asteroid field."
}
```

`created_at` is generated by the server and cannot be supplied by clients. Invalid IDs return `404`; invalid request data returns `400`.

## Postman

Import [`postman/Space-Bounty-API.postman_collection.json`](postman/Space-Bounty-API.postman_collection.json) into Postman. Set the `baseUrl` collection variable to `http://localhost:8080` if needed.
